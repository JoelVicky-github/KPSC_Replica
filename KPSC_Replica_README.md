# KPSC Website Clone

A static frontend replica of the **Karnataka Public Service Commission (KPSC)** website, built to practice HTML5 structure and CSS3 styling.

## Project Overview

This project recreates the look and layout of the official KPSC website using only HTML and CSS. It was created as a hands-on exercise to understand:

- Semantic HTML structure
- CSS layout techniques
- Responsive design basics
- Styling a multi-section webpage

## Features

- Clean HTML5 structure
- CSS3 styling (layout, colors, typography)
- Multi-section homepage layout
- Basic responsiveness

## Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure and content |
| CSS3 | Styling and layout |

## How to View

1. Clone or download the repository
2. Open `index.html` in any modern browser

No build step or server is required — it is a pure static site.
